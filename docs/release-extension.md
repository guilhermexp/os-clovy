# Browser packaging

The browser extension and native messaging shim have been retired. Clovy ships
its own pinned browser and private agent-browser host; there is no extension
installation, pairing, shared personal tab, or store publication step.

The packaging and resource verification procedure is documented in
[development.md](development.md#pinned-browser-resources),
[release-macos.md](release-macos.md) and [release-windows.md](release-windows.md).
