# Private sharing (retired)

Private link sharing was removed on 2026-10-28. The app no longer offers a
Share dialog, creates encrypted snapshots or share links, stores local sharing
keys, or runs a viewer service. There is no replacement sharing service.

The earlier design remains in Git history. This file is a retirement notice,
not a product contract or deployment guide. The decision and compatibility
trade-off are recorded in
[ADR-0073](adr/0073-desktop-calls-user-providers-without-a-clovy-server.md).
